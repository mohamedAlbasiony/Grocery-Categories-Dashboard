# Grocery Categories Dashboard 🛒🥦

A modern, responsive dashboard interface for a grocery and fresh categories store, built using HTML5 and CSS3 with a clean and mobile-friendly design.

## 🚀 Features
- **Responsive Layout:** Adapts seamlessly to all screen sizes (Mobile, Tablet, Desktop) using CSS Flexbox and CSS Grid.
- **Dynamic Price Badges:** Utilizes HTML5 `data-*` attributes and CSS `attr()` for scalable price tags.
- **Search & User Bar:** Functional header design with search input, notifications, and profile action items.
- **Promotional Banners:** Highlighted offers and discount cards with clean visual hierarchy.
- **Category Navigation:** Clean sidebar layout displaying all available product categories.

## 🛠️ Built With
- **HTML5** (Semantic Markup)
- **CSS3** (Flexbox, CSS Grid, Custom Attributes, Media Queries)
- **FontAwesome** (Icons)
- **Google Fonts** (Cairo)
